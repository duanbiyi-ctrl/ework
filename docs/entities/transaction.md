# Transaction LDM

[← Back to Entity Catalog](../index.md)

## Overview

**LDM Name:** `transaction`

**Description:** Purchase transactions, currently limited to transactions with deals applied.

**Primary Key:** `item_id`, `transaction_id`

**Relationship Type:** Child Entity (belongs to Item via 1:N relationship)
