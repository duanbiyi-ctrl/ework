# Variation LDM

[← Back to Entity Catalog](../index.md)

## Overview

**LDM Name:** `variation`

**Description:** Multi-SKU variations of a listing (e.g., different sizes/colors of the same product).

**Primary Key:** `variation_id`

**Relationship Type:** Child Entity (belongs to Item via 1:N relationship)
