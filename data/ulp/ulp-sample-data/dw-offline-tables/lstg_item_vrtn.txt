Overview

This table contains all information about the variations in the listing.
The purpose of the table is to capture data relevant to items which have Multi SKU information. There will be a record inserted in this table for each sku/variation on the parent item.
Use DLT_STS_YN_IND to get the current live variations

Sample SQL

Sample Query


SELECT
  l.auct_type_code,
  l.item_site_id,
  CASE WHEN item_rollups.available_quantity > 0 THEN 'Y' ELSE 'N' END AS multi_sku,
  COUNT(*) AS listings,
  SUM(COALESCE(item_rollups.available_quantity, l.qty_avail)) AS total_qty_available,
  SUM(COALESCE(item_rollups.variations, 1)) AS variations_plus_items,
  SUM(COALESCE(item_rollups.sold_quantity,0)) AS sold_from_live_lists
FROM
  access_views.dw_lstg_item l
  LEFT JOIN (
  SELECT
    v.item_id
    ,COUNT(*) AS variations
    ,SUM(qty - sold_qty) AS available_quantity
    ,SUM(sold_qty) AS sold_quantity
  FROM
    access_views.lstg_item_vrtn v
  WHERE
    v.auct_end_dt >= '2011-10-11'
    AND v.dlt_sts_yn_ind = 'N' /* Not deleted variations */
  GROUP BY
    1
  ) item_rollups ON (l.item_id = item_rollups.item_id)
WHERE
  l.auct_end_dt >= '2011-10-11'
GROUP BY
  1,2,3
