    Overview

    LDM Name: ItemRoot LDM

    Description: Current-state identity and broad listing data for one item or variation.

    NuDocument Docset: __ROOT__

    Keyspace: ItemKeyspace

    Source Class: com.ebay.app.cls.nudata.itemkeyspace.__ROOT__

    Primary Key: PK

    Relationship Type: Root document for current-state item data

    Fields

    The item root is the broadest item document. It combines listing identity, seller and location, lifecycle, category, policy references, flags, and item features. Fields inside embedded value objects are not separate NuDocument docsets.

    Write and Read Behavior

    Create and replace operations build this root with DocumentConverter.getRoot(...) and write it with the item child docsets in one transactional request. Partial category, price and quantity, hold, and media operations can update selected root fields without rebuilding the full document. CoreItemProcessor reads the root with multi-docset item requests.

    Relationships

    The root shares an item ancestor with ItemCompatibility, ItemDescription, ItemQtyPrice, ItemDetails, BusinessPolicies, and ItemLock. It is a current-state item document, not a relational parent table.
